# Chore Pilot – Planned for Next Version(s)

This document lists features and behaviour that are **not** in v1 but are planned for a future version (v2 or later). They are out of scope for the current proof-of-concept.

- **Multi-object chores** – Chores that are associated with more than one object (e.g. “inspect all gutters and roof”). v1 has one object per chore only.
- **Undo or soft delete** – Undo after removing an object or warranty, or a “trash” that allows restore. In v1, removal is permanent.
- **Planned / scheduled repairs** – Scheduling or planning repairs in advance (e.g. “Boiler repair scheduled for next week”). v1 focuses on logging repairs after the fact (what was done, when, cost, materials); planned repair dates and “due” repairs in the calendar sense are planned for v2.

When a planned item is committed for a specific version, it should be reflected in the PRD and UserStories for that version; this document can then be updated or the item removed.
